This is credited stock training footage, not Mohammed Khattab's work or a student result. All three files use the same source footage, have no audio track, and load only on an explicit playback click.

- raw: first 8 seconds, downscaled to 720px.
- calm: source seconds 1–7, mild contrast/saturation adjustment.
- energetic: three 1.4-second cuts starting at seconds 1, 4, and 7, slightly stronger contrast/saturation adjustment.
- poster: source frame at second 1, 720px WebP.

The website adds the selected caption as an HTML overlay; it is not burned into the MP4. Replace this entire training set with an authorized raw/final pair when available, updating `app/data/first-edit.ts` and the visible credit together.
