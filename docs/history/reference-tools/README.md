# Archived reference tools

These scripts belong to the initial workshop reconstruction. They are retained as provenance, not active build/test tools. Their `content/reference` inputs and `content/workshop.html` outputs refer to the former workspace and must not be used to regenerate the unified project.

Current design checks are `tests/reference-copy.spec.ts`, `tests/reference-design.spec.ts` and the architecture/visual acceptance checks documented in the root README. Portfolio stylesheet generation remains active at `scripts/prepare-portfolio-styles.py` and reads `docs/evidence/portfolio-reference/style.css`.
